About this project

Built to make tracking visible

FreeFollowers is an open-source privacy tool built as part of a data science research project. It uses a browser extension to intercept network requests in real time and visualises the resulting tracker graph — no data is stored on our servers beyond your current session.

Tracker classification is powered by the Disconnect.me open-source tracker protection list, the same list used by Firefox's private browsing mode.
