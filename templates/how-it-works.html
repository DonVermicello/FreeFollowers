Architecture & Privacy

Everyone watches you.
We keep our eyes closed.

FreeFollowers shows you who is tracking you — without tracking you itself. Here is exactly how it works and what we never collect.

🔒

Everything runs locally in your browser

The extension intercepts network requests entirely within your browser process. Cookie values are never read and never sent anywhere. The only data that reaches our server is a list of domain names — no URLs, no page content, no personal information. Your session is held in memory and deleted automatically after 2 hours.

Step by step — what happens when you browse
1
You visit a website
You open any website in Edge or Chrome. FreeFollowers does not interfere with or slow down page loading in any way.
In your browser
2
The extension watches network requests
While the page loads, the browser makes dozens of background requests to ad networks, analytics scripts and social widgets. The extension intercepts these using the browser's built-in webRequest API and extracts only the target domain name. No URLs, no content, no cookie values.
Local only
3
A graph is built in memory
The extension builds a graph: the site you visited → the tracker domains it contacted. Edges are annotated with cookie names (not values) observed in request headers. Everything happens inside your browser process — nothing leaves yet.
Local only
4
Only domain names are sent to the server
Every 3 seconds the extension sends a small JSON payload: your anonymous session ID, a list of domain name nodes, and a list of edges. Nothing else. The session ID is a random hex string — it does not identify you in any way.
freefollowers.ch
5
Your graph renders live in the browser
The graph page polls the server every 2 seconds and updates the force-directed visualisation. Tracker domains are classified using the open-source Disconnect.me list — the same list used by Firefox's Enhanced Tracking Protection. Hover any node to see what the company does with your data.
In your browser
6
Session data is automatically deleted
The server stores graph data in memory only — no database, no disk writes. A cleanup process runs every 5 minutes and deletes any session not updated in the last 2 hours. There is no way to recover session data after it expires.
Auto-deleted after 2h
